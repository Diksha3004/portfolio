# Diksha Kashid - Personal Portfolio

A sleek, responsive, modern personal portfolio website built with clean HTML5, CSS3, and JavaScript, deployed automatically on Vercel via GitHub.

## 🚀 Features
- **Hero Section**: High-impact introduction with quick links.
- **About Me**: Professional summary & stats.
- **Skills**: Categorized competencies (Frontend, Tools, Core).
- **Projects**: Showcase of key work and repositories.
- **Contact**: Direct email and GitHub links.
- **Mobile Responsive**: Fully responsive layout across all screen sizes.

## 🌐 Deploy to Vercel
This repository is connected to Vercel for continuous deployment. Every commit to `main` automatically updates the live website.
